# ADR 0001 — .NET 10 LTS

## Status

Accepted

## Context

LedgerX is a portfolio system that should look like a current enterprise stack, not a tutorial on an outgoing LTS.

## Decision

Target `net10.0` with C# latest, ASP.NET Core, and EF Core 10. Pin Microsoft packages to the installed 10.0.8 band so local SDK 10.0.300 / runtime 10.0.8 can build without preview feeds.

## Consequences

Interviewers see current LTS choices. Preview packages are avoided.
